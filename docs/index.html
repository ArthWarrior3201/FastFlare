FastFlare
CAPTCHA Speed Test EnvTime Live speed test GitHub

Three tools. One tiny server.

Stop bots without making people click traffic lights, measure real speed to a chosen provider and city, and run a time server that agrees with the internet's majority. No dependencies, one node process.

1 · Bot protection

Invisible proof-of-work plus behaviour signals. No "select all squares with a bus". Drop-in widget and a one-call server check.

Integrate it →

2 · Speed test

Choose a provider, then a city it runs in, and test download, upload, latency and jitter against that exact server, with graphs.

Integrate it →

3 · EnvTime

Asks Google, Apple, Windows and more over NTP, kicks any that disagree with the majority, then serves precise time over HTTP and NTP. Windows can use it as its time server.

Set it up →

Run it

git clone https://github.com/ArthWarrior3201/FastFlare.git
cd FastFlare
FF_SECRET=$(openssl rand -hex 32) node src/server.js
# HTTP on :8787. NTP on udp/123 needs privileges: use NTP_PORT=1230 to try it unprivileged.

Node 20 or newer. Nothing to npm install. The same server hosts these docs, the widget (/fastflare.js), the speed test client (/fastflare-speedtest.js) and the live demos.

Configuration

VariableMeaning
PORT, HOSTHTTP listen address (default 8787, 0.0.0.0).
FF_SECRETSigning secret for CAPTCHA challenges and tokens. Set it, or tokens die on restart.
config/sites.jsonYour CAPTCHA site keys and secrets. See CAPTCHA docs.
FF_PROVIDER, FF_CITY, FF_COUNTRY, FF_PUBLIC_URLWhat this node is, for the speed test list. See Speed Test docs.
config/servers.jsonOther speed test nodes this registry should list.
NTP_PORT, FF_NTP=0UDP port for the NTP server (default 123), or switch it off.
FF_TIME_PROVIDERSComma-separated upstream NTP hosts. See EnvTime docs.
TRUST_PROXY=1Read the client IP from CF-Connecting-IP / X-Forwarded-For when behind a proxy.
