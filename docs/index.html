Get started

On any Ubuntu or Debian server, one command installs and starts everything:

curl -fsSL https://raw.githubusercontent.com/ArthWarrior3201/FastFlare/main/deploy/install.sh | sudo bash

Prefer to run it by hand? It needs only Node.js 20 or newer and has nothing to install:

git clone https://github.com/ArthWarrior3201/FastFlare.git
cd FastFlare
FF_SECRET=$(openssl rand -hex 32) node src/server.js

The server also hosts this documentation, the widget (/fastflare.js), the speed test client (/fastflare-speedtest.js) and the live demos.

Configuration

SettingMeaning
PORT, HOSTWeb API listen address (default 8787).
FF_SECRETSigning secret for CAPTCHA tokens. The installer generates one.
config/sites.jsonYour CAPTCHA site keys. See the CAPTCHA guide.
FF_PROVIDER, FF_CITY, FF_COUNTRY, FF_PUBLIC_URLLabel this server for the speed test list. See the speed test guide.
config/servers.jsonOther speed test servers to list.
NTP_PORT, FF_NTP=0Time server UDP port (default 123), or turn it off.
FF_TIME_PROVIDERSUpstream time sources. See the EnvTime guide.
TRUST_PROXY=1Read the visitor IP from proxy headers when running behind one.
